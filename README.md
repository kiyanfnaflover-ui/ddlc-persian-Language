# 📖 About

This project adds **Persian (فارسی)** as a brand-new language option to **Doki Doki Literature Club**.

Unlike traditional translation mods that overwrite the original game files, this project integrates Persian directly into the **Language Settings**, allowing players to switch between **English** and **Persian** whenever they want.

The original English localization remains completely intact.

---

# ✨ Features

* 🇮🇷 Adds Persian as a new language.
* ⚙️ Persian appears in the Settings menu.
* 🌍 Original English remains available.
* 🔄 Instantly switch between languages.
* 💬 Persian interface and dialogue support.
* 🎮 Designed specifically for DDLC.
* 🛠 Clean and organized Ren'Py implementation.

# 🚀 Installation

1. Download or clone this repository.
2. Copy the mod files into your DDLC installation.
3. Launch the game.
4. Open:

```
Settings
      ↓
Language
      ↓
فارسی (Persian)
```

5. Enjoy playing DDLC in Persian!
